# Matchmaking System

## 💡 Project Description
A Spring Boot-based matchmaking web application with user registration, login, and admin dashboard. Integrates with a SQLite/MySQL database to manage user profiles and matches.

---

## 🚀 How to Set Up and Run

### Prerequisites
- Java 17+
- Maven
- Spring Boot
- SQLite

### Steps to Run
1. Clone the repository:
git clone

3. Open the project in IntelliJ or any IDE.
4. Configure your database in `application.properties`.
5. Run the project using:
mvn spring-boot:run

---
## 📦 Dependencies
- Spring Boot
- Spring Web
- Spring Data JPA
- SQLite/MySQL JDBC Driver
- Bootstrap (for frontend)
